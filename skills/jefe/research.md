# Research and brainstorming

Read for a research or brainstorming request. It is a job (a project when it has many parts) and follows the SKILL.md recipe with these changes.

1. Message 1 holds several `jefe:researcher` calls in parallel, one per angle (`model:` the scout's, from the `models:` line), each briefed with the `Gate:` line, the question and "findings with sources, 200 words".
2. One `jefe:builder` then writes one document in which every claim is followed by its source. Its brief carries the researchers' findings pasted in; this is the one brief allowed to exceed 40 words.
3. DONE WHEN is `sh .jefe/check.sh` (the builder writes a short script, for example that every claim line has a source) plus the reviewer.
4. The reviewer checks that each source exists and supports its claim, and that every question the user asked is answered or listed as not established.
